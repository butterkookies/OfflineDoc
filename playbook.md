## 1. Mandatory Agent Guardrails (Paste into Every Agent Session)

Every AI coding assistant or autonomous agent (Antigravity, Devin, Claude, etc.) operating in this repository **must** adhere strictly to the following 12 non-negotiable guardrails:

```text
================================================================================
OFFLINEDOC AGENT GUARDRAILS (STRICT COMPLIANCE)
================================================================================
1. 100% LOCAL INFERENCE & AIRPLANE MODE PURITY (R6, R8):
   - All AI computation (whisper.cpp, llama.cpp) must run strictly on-device.
   - NEVER add calls to cloud AI APIs (OpenAI, Anthropic, Gemini, Hugging Face, etc.).
   - NEVER import external web fonts (Google Fonts), CDN scripts, stylesheets, or telemetry.
   - The application must load and function completely when Wi-Fi and ethernet are disabled.

2. LOCALHOST NETWORK BINDING ONLY:
   - All servers (FastAPI backend, llama-server) must bind strictly to 127.0.0.1.
   - Do not bind to 0.0.0.0 or any external interface.

3. PRIVACY & SYNTHETIC DATA ONLY (RESPONSIBLE AI):
   - NEVER use, ingest, or commit real patient health information or personal identities.
   - All fixtures, voice clips, test cases, and demo scenarios must use synthetic data only
     and be explicitly labeled as synthetic.

4. HONEST EVALUATIONS — NO INVENTED BENCHMARKS (R5):
   - Never fabricate, estimate, or hallucinate benchmark numbers, latencies, or accuracy percentages.
   - Any metric cited in documentation, slides, or README must come directly from raw outputs
     generated by `eval/run_eval.py` and committed to the repository.

5. TRANSPARENT SAMPLE & FALLBACK LABELING (R5, R7):
   - A cached, replayed, or pre-recorded fallback run must NEVER pretend to be a live recording.
   - If a mock or pre-recorded sample is loaded, display a persistent, visible
     "SAMPLE / NOT LIVE" badge in the UI.

6. "NULL-NOT-GUESS" SCHEMA EXTRACTION:
   - If clinical data (e.g., blood pressure, weight, symptoms) was not explicitly stated in the
     transcribed audio, the extraction output MUST be null.
   - Never extrapolate, assume, or guess unmentioned clinical details.

7. VERBATIM EVIDENCE GROUNDING:
   - Every non-null extracted field must carry an exact quote (`evidence`) from the transcript.
   - If an evidence span cannot be matched, it must be marked `unverified` and flagged in the Review UI.

8. DOCUMENTATION AID ONLY — NO MEDICAL ADVICE:
   - OfflineDoc is solely an administrative documentation assistant for health workers.
   - NEVER generate medical diagnoses, drug dosage suggestions, treatment plans, or clinical triage alerts.

9. CONTINUOUS DISCLOSURE LOGGING (R4, R9, R12):
   - Every new library added to `requirements.txt`, model checkpoint placed in `models/`,
     binary in `bin/`, or AI development tool used must be immediately documented in `DISCLOSURES.md`.

10. CUT-LIST DISCIPLINE (PROTECT THE MVP):
    - Strictly honor the non-goals defined in `PROJECT_CONTRACT.md`.
    - Do NOT build or suggest databases (SQLite/Postgres), user accounts/auth, cloud sync,
      streaming ASR, Android wrappers, or multi-agent loops.

11. BOUNDED TASK EXECUTION:
    - Work strictly on one approved task card (`AG-xx`) per slice.
    - Do not make opportunistic edits to unrelated modules.
    - Always verify changes with unit tests or reproducible manual verification commands.

12. TIME WINDOW & CODE FREEZE (R14, R15):
    - Absolute submission deadline: 10:00 AM PHT, October 10, 2026.
    - Internal code freeze: 08:30 AM PHT, October 10, 2026.
    - No commits or modifications permitted after the deadline.
================================================================================
```

## 4. Emergency Fallback Playbook

If a critical technical blocker arises during development:

1. **Whisper Transcription Too Slow on Demo Laptop (>15s for 30s audio):**
   - *Action:* Fall back immediately from `ggml-base.en` to `ggml-tiny.en`. If still slow, shorten demo dictation length to 15–20 seconds.
2. **LLM Extraction Hallucination or Incomplete JSON:**
   - *Action:* Enforce strict GBNF grammar / JSON Schema constrained decoding in `llama-server`. Ensure temperature is pinned at `0.0`.
3. **Microphone Permission Fails During Pitch:**
   - *Action:* Immediately switch to the secondary fallback path in the UI: upload the pre-recorded synthetic demo WAV file or click "Load Sample Visit", which clearly displays the `[SAMPLE / NOT LIVE]` tag.
4. **llama-server Crash or Port Conflict:**
   - *Action:* `scripts/start.ps1` includes an auto-kill check for stale processes on port 8081 before restarting.
